# Agent 记忆系统

## 概述

TermMan 的 Agent 记忆系统为每个终端会话 (Item) 提供智能记忆管理，支持长期记忆存储、语义检索、自动去重和过期清理。

## 记忆类型

| 类型 | 名称 | 说明 | 颜色 |
|------|------|------|------|
| `fact` | 事实 | 用户名、路径、配置值等 | 蓝色 |
| `preference` | 偏好 | 代码风格、工具选择等 | 紫色 |
| `task` | 任务 | 待办事项、计划等 | 绿色 |
| `error` | 错误 | 已知问题和解决方案 | 红色 |
| `context` | 上下文 | 项目结构、依赖关系等 | 黄色 |

## API 端点

### 获取所有记忆
```
GET /api/v1/memory/{item_id}/memories?memory_type=fact
```

### 获取统计信息
```
GET /api/v1/memory/{item_id}/memories/stats
```

返回:
```json
{
  "total": 15,
  "by_type": {"fact": 8, "error": 5, "context": 2},
  "expired_count": 2,
  "memory_types": {"fact": "事实信息...", ...}
}
```

### 添加记忆
```
POST /api/v1/memory/{item_id}/memories
{
  "content": "项目使用 Python 3.11",
  "memory_type": "fact",
  "ttl_days": 30
}
```

### 搜索记忆
```
POST /api/v1/memory/{item_id}/memories/search
{
  "query": "Python 版本",
  "n_results": 5,
  "memory_type": "fact"
}
```

### 清理过期记忆
```
POST /api/v1/memory/{item_id}/memories/expire
```

### 去重记忆
```
POST /api/v1/memory/{item_id}/memories/deduplicate
```

### 压缩记忆
```
POST /api/v1/memory/{item_id}/memories/summarize?threshold=10
```

使用 LLM 将多条相似记忆压缩成摘要，减少存储空间。

参数:
- `threshold`: 触发压缩的最小记忆数量，默认 10

返回:
```json
{
  "summarized": 15,
  "summaries_created": 3,
  "message": "压缩了 15 条记忆，生成 3 条摘要"
}
```

## 前端组件

## 核心服务

### VectorStoreService

位置: `backend/app/services/agent/memory/vector_store.py`

```python
from app.services.agent.memory.vector_store import vector_store

# 添加记忆 (自动去重)
memory_id = vector_store.add_memory(
    item_id="uuid",
    content="重要信息",
    memory_type="fact",
    ttl_days=30
)

# 语义搜索
memories = vector_store.search_memories(
    item_id="uuid",
    query="搜索关键词",
    n_results=5,
    memory_type="fact"
)

# 获取统计
stats = vector_store.get_memory_stats("uuid")

# 清理过期
count = vector_store.expire_old_memories("uuid")

# 去重
count = vector_store.deduplicate_memories("uuid")

# 压缩 (使用 LLM 合并相似记忆)
result = vector_store.summarize_memories(
    item_id="uuid",
    model="deepseek/deepseek-chat",
    api_key="...",
    api_base="...",
    threshold=10
)
```

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `DEFAULT_MEMORY_TTL_DAYS` | 30 | 默认过期天数 |
| `DEDUP_THRESHOLD` | 0.95 | 去重相似度阈值 |
| `CHROMA_PERSIST_DIR` | data/chroma | ChromaDB 存储路径 |

## 自动功能

### 1. 自动去重
添加记忆时自动检查相似度，超过 95% 相似则跳过。

### 2. 自动过期
每条记忆都有 `expires_at` 字段，可通过 API 手动清理过期记忆。

### 3. 记忆压缩
使用 LLM 将多条相似记忆压缩成摘要：
- 按类型分组处理
- 保留关键信息，去除冗余
- 减少存储空间，提高检索效率

### 4. 记忆提取
对话中检测到关键词时自动提取重要信息存储:
- password, 密码, key, 密钥, token
- config, 配置, setting, 设置
- error, 错误, bug, 问题
- solution, 解决方案, fix, 修复
- important, 重要, remember, 记住

## 数据结构

### Memory 对象
```typescript
interface Memory {
  id: string              // UUID
  content: string         // 记忆内容
  metadata: {
    item_id: string       // 所属 Item
    memory_type: string   // 记忆类型
    created_at: string    // 创建时间 (ISO)
    expires_at: string    // 过期时间 (ISO)
  }
  distance?: number       // 搜索时的距离 (越小越相似)
}
```

### MemoryStats 对象
```typescript
interface MemoryStats {
  total: number                          // 总数
  by_type: Record<MemoryType, number>    // 按类型统计
  expired_count: number                  // 过期数量
  memory_types: Record<MemoryType, string>  // 类型说明
}
```

## 最佳实践

1. **合理设置 TTL**
   - 临时信息: 7 天
   - 常规信息: 30 天
   - 永久信息: 365 天

2. **定期维护**
   - 每周执行一次 `expire_memories`
   - 每月执行一次 `deduplicate_memories`

3. **记忆类型选择**
   - 不确定时使用 `fact`
   - 涉及用户选择时使用 `preference`
   - 错误修复后使用 `error`

4. **搜索优化**
   - 使用具体的查询词
   - 指定 `memory_type` 缩小范围
   - 合理设置 `n_results`

## MCP 工具

Agent 可通过 MCP 工具直接操作记忆：

### save_memory
保存重要信息到长期记忆。
```json
{
  "name": "mcp_local_save_memory",
  "arguments": {
    "content": "项目使用 Python 3.11",
    "memory_type": "fact",
    "ttl_days": 30,
    "item_id": "auto"
  }
}
```

### recall_memory
语义搜索相关记忆。
```json
{
  "name": "mcp_local_recall_memory",
  "arguments": {
    "query": "Python 版本",
    "n_results": 5,
    "memory_type": "fact",
    "item_id": "auto"
  }
}
```

### list_memories
列出所有记忆。
```json
{
  "name": "mcp_local_list_memories",
  "arguments": {
    "memory_type": "fact",
    "item_id": "auto"
  }
}
```

### delete_memory
删除指定记忆。
```json
{
  "name": "mcp_local_delete_memory",
  "arguments": {
    "memory_id": "xxx-xxx-xxx",
    "item_id": "auto"
  }
}
```

## Skill 集成

系统 Skill (`backend/skills/system/SYSTEM_PROMPT.md`) 已集成记忆功能：

### 自动记忆场景
1. 用户说"记住这个"、"下次记得"
2. 发现重要项目配置
3. 解决复杂问题后记录方案
4. 用户表达明确偏好
5. 发现项目特定约定

### 使用示例

**用户**: "记住这个项目用 pnpm 不用 npm"

**Agent 行动**:
```json
{
  "name": "mcp_local_save_memory",
  "arguments": {
    "content": "项目使用 pnpm 作为包管理器，不使用 npm",
    "memory_type": "preference",
    "ttl_days": 90
  }
}
```

**用户**: "这个项目的数据库端口是多少？"

**Agent 行动**:
```json
{
  "name": "mcp_local_recall_memory",
  "arguments": {
    "query": "数据库端口"
  }
}
```

**返回**: `[1] (fact, 相关度: 95%) 数据库端口: 5432`
