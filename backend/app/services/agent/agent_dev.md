现在我有后端和daemon端的socket连接
这个连接中心有订阅item发过来的消息和发送消息到daemon端的item的功能

目前我要做的是，终端发送过来的信息，经过inputfilter之后，到item对应的itemhandler里面的agent

前端不是有个sse的chat窗口吗？我需要agent处理过滤后的终端信息，发送到每个目标item连接的浏览器的chat窗口
。然后agent思考的过程也要发送到每个目标item连接的浏览器的chat窗口，就跟我和agent的对话一样，只是输入者可以是过滤后的终端信息

然后agent的接收队列算法是这样的
1. 接收信息，当agent没开始回复的时候就持续发送，除非信息就那么多。有新的输入就在一轮输入处理结束的时候新的输入给llm，然后他自己多轮对话处理
2. 当agent开始回复的时候，就停止发送，把多的信息放到队列里等待一轮会话结束。
3. 当agent回复结束的时候，就从队列里取信息，继续发送。


整体循环就是这样，终端输出给agent和用户对话的agent是同一个实例，也要存入同一个记忆，只是输入接口不同
